# CodeAlpha Internship Tasks

This repository contains the frontend development projects completed as part of my CodeAlpha Internship.

## Tasks

### Task 1 – Image Gallery
* Responsive and interactive web-based image gallery application.
* Features real-time category filtering (*Nature*, *Cities*, *Animals*), a full-screen lightbox modal, and smooth keyboard navigation.
* **Technologies:** HTML5, CSS3, Vanilla JavaScript.

### Task 2 – Calculator
* Web-based calculator interface inspired by the soft, organic color palette of Studio Ghibli films.
* Includes color-coded controls, CSS Grid keypad layout, interactive hover click feedback, error handling, and keyboard shortcuts.
* **Technologies:** HTML5, CSS3, Vanilla JavaScript.
